#### Issue #2: generate-test-video CLI handler uses CWD-relative path

**Description**: The `generate-test-video` command handler constructs the output path as `Path("test_assets/test_video.mp4")` (relative to CWD). If the user runs the CLI from a directory other than the project root, the video is created in the wrong location. The `generate_test_video.py` `__main__` block correctly uses `Path(__file__).parent / "test_video.mp4"` for robustness.

**Location**:
- File: `cli.py`
- Lines: `349-353`

**Offending Code**:
```python
elif args.command == "generate-test-video":
    from test_assets.generate_test_video import generate
    out = Path("test_assets/test_video.mp4")
    out.parent.mkdir(exist_ok=True)
    generate(out, duration=args.duration)
```

**Recommended Solutions**:
1. **Use the module's own path resolution** (Preferred)
   - Replace with: `out = Path(test_assets.generate_test_video.__file__).parent / "test_video.mp4"`
   - Or import and use a constant from the module.
   - Rationale: Works regardless of CWD.

2. **Accept as-is**
   - The deployment instructions explicitly `cd` to the project root first, and all other CLI commands assume CWD is the project root.
   - Trade-off: Consistency with existing CLI patterns vs. absolute robustness.
